FDev
===

# 概要

* Unreal Engine用プラグイン
* [tranp](https://github.com/rog-works/tranp)を用いたPython開発環境

# 機能(プラグイン)

* Core機能
  * アセットマネージャー
  * Json
* アセット生成
  * マテリアル関数

# 必須要件

## プラグイン

* Unreal Engine >= 5.8

## Python開発環境

* Python >= 3.13
* [tranp](https://github.com/rog-works/tranp) >= 0.9.19
* [PyYAML](https://pypi.org/project/PyYAML/) >= 6.0.2
